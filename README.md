# Portfolio de Mohamed Kharrat

Site portfolio bilingue français / anglais, prêt pour GitHub Pages.

## Publication
1. Décompressez l’archive.
2. Déposez à la racine du dépôt GitHub les fichiers `index.html`, `style.css`, `script.js`, `cv-fr.pdf` et `cv-en.pdf`.
3. Validez les changements (Commit changes).
4. Dans Settings > Pages, vérifiez que GitHub Pages publie depuis la branche `main` et le dossier `/ (root)`.

Le site s’ouvre en français par défaut. Le choix FR/EN est mémorisé dans le navigateur et le bouton de téléchargement propose automatiquement le CV PDF dans la langue affichée.


Le sélecteur FR / EN est visible directement dans l’en-tête sur mobile, sans ouvrir le menu.
