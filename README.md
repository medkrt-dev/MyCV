# Portfolio — Mohamed Kharrat

Portfolio CV statique en HTML, CSS et JavaScript, adapté à GitHub Pages.

## Avant publication
- Vérifier les dates et descriptions des missions (résumées depuis le CV).
- Compléter la langue indiquée `[à préciser]`.
- Vérifier que tu souhaites rendre ton CV PDF public : il contient des coordonnées personnelles. Le site n'affiche pas ton adresse postale ni ton numéro de téléphone.
- Tu peux remplacer `cv.pdf` par une version expurgée de tes coordonnées privées si tu préfères.

## Publier sur GitHub Pages
1. Ouvre le dépôt `medkrt-dev.github.io`.
2. Clique sur **Add file → Upload files**.
3. Envoie `index.html`, `style.css`, `script.js` et `cv.pdf` depuis ce dossier.
4. Clique sur **Commit changes**.
5. Dans **Settings → Pages**, choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save** si ce n'est pas déjà activé.
6. Attends quelques minutes puis ouvre https://medkrt-dev.github.io/.

Le site est statique : aucun serveur ni abonnement payant n'est nécessaire. GitHub Pages est gratuit pour les dépôts publics éligibles.
